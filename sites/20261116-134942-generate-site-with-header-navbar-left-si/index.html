Overview

Header on top, navigation on the left, footer below.

Atlas is a ready-to-use page structure. The header stays in view, the navigation sits on the left side, and the footer closes the page. Replace this text with your own.

See the features How it is built

Features

What you get

  • Responsive

    On small screens the left navigation turns into a slide-in menu opened from the header.

  • Accessible

    Semantic landmarks, a skip link, visible focus outlines and full keyboard support.

  • No dependencies

    Plain HTML, CSS and JavaScript. Nothing to install and nothing loaded from elsewhere.

  • Light and dark

    Colours follow the visitor's system preference automatically.

Layout

Three parts, one grid
