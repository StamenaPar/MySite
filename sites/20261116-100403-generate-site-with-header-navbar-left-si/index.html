Overview

A header, a left navigation bar and a footer — done properly.

Atlas is a ready-to-use page shell. The header stays in view, the navigation sits on the left, and the footer closes the page. Drop your content into the middle and you are set.

See the features How it is built

Features

What you get

  • Sticky header

    The header holds the brand and a primary action, and remains visible while the page scrolls.

  • Left-side navigation

    A fixed sidebar on wide screens that becomes a slide-in drawer on phones and tablets.

  • Footer

    A full-width footer with secondary links, always resting at the bottom of the page.

  • Accessible

    Landmarks, a skip link, visible focus styles, keyboard support and reduced-motion handling.

  • Light and dark

    Colours follow the visitor's system preference automatically, with readable contrast in both.

  • No dependencies

    Plain HTML, CSS and JavaScript. Nothing to install, nothing to build.

Layout

How the page is put together

The page is a CSS grid with three areas stacked around the main content.

Header
Nav
Main content
Footer
  1. Header spans the full width and sticks to the top.
  2. Navigation occupies a fixed-width column on the left and highlights the section you are reading.
  3. Main content fills the remaining space and scrolls with the page.
  4. Footer spans the full width beneath everything else.
