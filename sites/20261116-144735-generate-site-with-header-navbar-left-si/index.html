Overview

A simple site with a header, a left navigation bar and a footer.

Harbor is a tidy starting point: a header that stays in view, navigation anchored on the left, and a footer that closes every page. It adapts from phones to wide screens.

Explore features See the layout

Features

Everything a solid page needs

Responsive

On small screens the left navigation tucks into a slide-out drawer opened from the header.

Accessible

Semantic landmarks, a skip link, visible focus styles and full keyboard support.

Light and dark

Follows your system preference, with a toggle in the header to switch at any time.

No dependencies

Plain HTML, CSS and JavaScript. Nothing to install, build or load from elsewhere.

Layout

Three regions around your content

  1. Header — holds the brand, the theme switch, the cart and a primary action. It stays at the top while you scroll.
  2. Left navigation — lists every section and marks the current one. It stays in place beside the content.
  3. Footer — spans the full width with secondary links and the copyright line.

FAQ

Common questions

Does the navigation work without JavaScript?

Yes. Without JavaScript the navigation is shown as a normal block of links and every link still jumps to its section.

How do I add a navigation item?

Add a list item with a link to the navigation list, and a section with the matching id in the main content.

Can I change the colours?

All colours are CSS custom properties at the top of the stylesheet, for both the light and dark themes.

How does the shopping cart work?

Open any fruit or vegetable page, choose a quantity and select “Add to cart”. The cart is saved in your browser and opened from the header. It is a demonstration only: prices are samples and no payment is taken.
